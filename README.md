# Re.Myprofile

3Dワールドを探索しながら、プロフィール・スキル・制作物・学外活動・取得資格・釣果を閲覧できる自己紹介サイト。

## 技術スタックと役割

| 技術 | 実装した機能・役割 |
|---|---|
| **HTML5 / CSS3 / JavaScript（ES Modules）** | ページ構造、UI、ステージ切り替え、状態管理。CSSでレスポンシブ表示と各画面のデザインを制御 |
| **WebGL / GLSL** | ボクセル調の3Dワールド、床・ブロック・キャラクター・ホワイトボードの描画。深度バッファによるオブジェクトの前後判定 |
| **HTML-in-Canvas** | 5つのホワイトボードのHTML文書をWebGLテクスチャとして3D面に配置。スクロールなどで内容が変化した場合に限りテクスチャを更新 |
| **CSS 3D Transforms** | HTML-in-Canvas非対応環境向けの代替表示。通常のHTMLによる本文閲覧を提供 |
| **Canvas 2D API** | 採掘オープニングの描画、3Dボード上部のタイトル用テクスチャ生成 |
| **Pointer / Touch / Wheel Events** | ドラッグ・スワイプによる視点回転、ズーム、移動。ボード閲覧時とギャラリー表示時の入力制御 |
| **HTML `<dialog>` / 画像の遅延読み込み** | 釣り上げ演出から開く釣果ギャラリー、独立スクロール、写真拡大表示 |

## 機能構成

- **3Dワールド**：6ステージ（PROFILE / SKILLS / PROJECTS / QUEST LOG / BADGES / FISHING）を正面に固定したカメラで切り替える。
- **展望台**：QUEST LOG と BADGES の間、ホワイトボードより少し後ろに梯子を配置。QUEST LOG から → キー（または「梯子へ」）で梯子前へ移動し、↑ キーで上る。「望遠鏡をのぞく」をクリックすると、画面いっぱいに広げた薄い縁の長方形の視界から360度見回せる。覗き始めは等倍で、右側のレンズ外にある縦スライダーで1〜3倍に調整できる。観察中は通常のHUDを隠し、倍率調整と「戻る」だけを表示。ドラッグ・スワイプ・矢印キーで視線を動かし、ホイール・ピンチ・＋/−でも最大3倍まで変更可能。Esc で足場の固定視点へ戻り、↓ キーまたは「下りる」で地上へ戻る。
- **プラネタリウム風の球体空間**：島全体を包む真球の内面に、高い空へ弧を描くオーロラと約5,200個の星を配置。四角い光の粒を残しながら、カーテン状の重なり、明るい帯の縁、柔らかな発光で奥行きを表現する。紫・ピンクから青・青緑へ約40秒かけて移り、約80秒で一巡。WebGLとCSS 3Dで同じ球面・カメラを使用し、星には穏やかな瞬きを加える。星の配置は演出用。WebGL非対応時は同じ光の設定から生成したSVGパノラマを使う。
- **ホワイトボード**：最初の5ステージに連続したHTML文書を配置。各ボードのスクロール位置を保持し、リンク操作に対応する。
- **釣果ギャラリー**：第6ステージの釣り糸を操作して開く。写真は `image/fish1.jpg` から連番で参照し、ギャラリーのスクロールをワールド操作より優先する。
- **描画の軽量化**：3Dカメラの移動ではHTMLテクスチャを更新せず、変更のあったボードのみ更新する。前景オブジェクトの二重描画は行わない。

## ディレクトリ構成

| パス | 役割 |
|---|---|
| `index.html` | エントリーポイント |
| `js/content/` | 自己紹介・各ボードの文章、リンク、釣果設定 |
| `js/data/` | コンテンツの統合とステージ定義 |
| `js/scene/` | WebGL、HTML-in-Canvas、CSS 3D代替描画 |
| `js/ui/` | 文書生成、カメラ操作、ナビゲーション、スクロール管理 |
| `js/intro/` | 採掘オープニング |
| `js/fishing/` | 釣り演出・ギャラリー制御 |
| `css/` | 表示スタイル・レスポンシブ対応 |
| `assets/` | キャラクター画像などの共通素材 |
| `image/` | 釣果写真（後から追加） |
| `tests/` | Node.js標準テストランナーによる回帰テスト |
| `tools/` | ローカル開発サーバー |

## 開発

Node.jsを使用したローカル確認と自動テスト：

```bash
npm run dev
npm test
```
